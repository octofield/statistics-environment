## 一、圖表

### x 軸的文字重疊、擠在一起
```python
plt.xticks(rotation=45, ha='right')    # 斜 45 度，靠右對齊
```
還是太擠：把圖拉寬 `plt.figure(figsize=(12, 5))`（寬, 高，單位英吋，要寫在畫圖之前），或縮小字體 `sk.setup(size=12)`。
用 `ax` 畫圖時：`ax.tick_params(axis='x', labelrotation=45)`。

### 標題或座標軸文字被切掉、擋到別的子圖
```python
plt.tight_layout()                     # 自動調整間距（放在 plt.show() 前）
```
存成圖檔時文字被切掉：`plt.savefig('fig.png', bbox_inches='tight')`。
子圖之間太近：`plt.subplots(1, 2, figsize=(14, 5))` 把整張圖拉大，或 `fig.subplots_adjust(wspace=0.4, hspace=0.4)`。

### 圖例（legend）擋到資料
```python
plt.legend(loc='upper left')                          # 換位置：'upper right'、'lower left'、'best'…
plt.legend(bbox_to_anchor=(1.02, 1), loc='upper left') # 放到圖的外面（右側）
```

### 標題太長
用 `\n` 換行：`plt.title('第一行\n第二行')`，或縮小字體：`plt.title('...', fontsize=12)`。

### 中文變成方塊 □□□
重新執行 `sk.setup()`。還是不行就檢查是不是在 `sk.setup()` **之前**就畫了圖。

### ≥、≤、負號變成方塊
`sk.setup()` 已經處理好了（中文字型缺的符號會自動改用 DejaVu Sans，負號也已關閉 unicode 負號）。
沒有用 statkit 的話：`plt.rcParams['axes.unicode_minus'] = False`。

### 圖太小 / 太大
- 單張圖：`plt.figure(figsize=(10, 6))`
- 全部的圖：`sk.setup(dpi=120)`（越大圖越大）

### 好幾張圖疊在同一張上
每張圖畫完都要 `plt.show()`；或在畫下一張之前先 `plt.figure()`。

### 散佈圖的點太密、看不清楚
```python
plt.scatter(x, y, s=10, alpha=0.4)     # s：點的大小、alpha：透明度（0～1）
```

### 圖看起來很陽春，想更好看
`sk.tidy(ax)` 一行套用：去掉上、右框線、淡格線、千分位、長條上標數值（`bar_labels=True`），並印出等價的寫法；snippets `tidy`、`barlabel`、`thousands`。完整的原則與範例見 `notes/01_視覺化.ipynb` 的「讓圖更好看」。

### 想在長條上標數字
```python
bars = plt.bar(labels, values, facecolor='lightgrey', edgecolor='black')
plt.bar_label(bars, fmt='%.2f')        # 小數兩位；整數用 '%d'
```

### 圖沒有出現
cell 最後要有 `plt.show()`；如果是 `sk.xxx(...)` 畫的圖，後面也加一行 `plt.show()`。

## 二、畫面與輸出

### 滑鼠停住時跳出的說明框擋住程式碼
按 **Esc** 或把滑鼠移開就會消失。打字時跳出的自動完成清單也是按 **Esc** 關掉。

### 輸出太長，擋住後面的 cell
- VS Code 已經設定成太長的輸出會自動變成可以捲動的區塊
- 摺疊或清除輸出：按 **Ctrl+Shift+P** 打開命令選擇區，輸入「輸出」，選「摺疊儲存格輸出」或「清除儲存格輸出」
- JupyterLab：點輸出**左邊的藍色長條**可以摺疊；右鍵 →「Clear Outputs」可以清除
- 從源頭減少：只印需要的東西，例如 `df.head()` 而不是 `df`、`print(round(x, 4))`

### 程式碼太長，超出畫面右邊
**Alt+Z** 切換自動換行（VS Code）。

### 側邊欄、下方面板擋住畫面
| 按鍵 | 功能 |
|---|---|
| Ctrl+B | 顯示 / 隱藏左側檔案總管 |
| Ctrl+J | 顯示 / 隱藏下方面板（終端機、問題） |
| F11 | 全螢幕 |
| Ctrl+K 然後 Z | 禪模式（只剩編輯區，按兩次 Esc 離開） |
| Ctrl+= / Ctrl+- | 放大 / 縮小整個畫面（Ctrl+滑鼠滾輪也可以） |
| Ctrl+數字鍵 0 | 恢復原本大小 |

### DataFrame 的欄位或列被省略成「...」
```python
pd.set_option('display.max_columns', None)   # 欄位全部顯示
pd.set_option('display.max_rows', 200)       # 最多顯示 200 列
df.T                                          # 欄位太多時轉置，直的看
```

### 小數太長
```python
round(x, 4)                          # 單一數字
print(f'{x:.4f}')                    # 印出時取 4 位
df.round(4)                          # 整個 DataFrame
pd.set_option('display.precision', 4)
```

### 數字顯示成科學記號（1.2e-05）
`print(f'{x:.6f}')`，或 `pd.set_option('display.float_format', '{:.6f}'.format)`。

## 三、執行問題

### 選不到 Kernel / 右上角一直顯示「選取核心」
按右上角「選取核心」→「Python 環境」→ 選路徑裡有 **WPy64-313150** 的那個。
沒有出現的話，關掉 VS Code，重新從隨身碟雙擊 `1_啟動VSCode.bat`（不要直接開 Code.exe）。

### cell 一直顯示 [*] 或轉圈圈，跑不完
- VS Code：上方工具列按「中斷」，還是不行就按「重新啟動」
- JupyterLab：Kernel → Interrupt Kernel；或按 Esc 再按兩下 I
- 常見原因：迴圈太多次、`input()` 在等你輸入、模擬次數設太大

### `FileNotFoundError`：找不到檔案
- **老師的考卷**寫 `pd.read_excel('檔名.xlsx')`（沒有路徑）→ 資料要跟考卷放在**同一個資料夾**（`exam/`）。用 `5_匯入考卷` 匯入時，如果資料跟考卷在同一個資料夾（例如都在「下載」），會自動一起複製
- **自己練習**時資料放 `data/`、notebook 在 `exam/` → 路徑要寫 `'../data/檔名.xlsx'`
- 檔名要完全一樣（含副檔名 `.xlsx` / `.csv`）。不確定就先 `import os; print(os.listdir('.'))` 看目前資料夾有哪些檔案
- Excel 工作表名稱不確定：`pd.ExcelFile('檔名.xlsx').sheet_names`

### `ModuleNotFoundError: No module named 'statkit'`（或其他套件）
Kernel 選錯了，選到考場電腦本機的 Python。照上面「選不到 Kernel」重選隨身碟的那個。

### `NameError: name 'xxx' is not defined`
變數是在前面的 cell 定義的，但那格還沒執行（或 Kernel 重新啟動過）。從上面開始依序執行，或直接 Run All。

### 結果怪怪的、跟預期不一樣
可能是 cell 執行順序亂了（改了上面的值、卻沒重新執行）。**重新啟動 Kernel → 全部執行**，從頭跑一次。

### 想看目前所有變數的值
- VS Code：notebook 上方工具列按「**Jupyter 變數**」，下方面板會列出所有變數、型態、大小（DataFrame 還可以點開看表格）
- JupyterLab：右上角開啟偵錯（蟲的圖示），右側「Variables」面板
- 兩邊都可以：在 cell 裡執行 `%whos`

### 不小心刪掉 cell
- VS Code：按 Esc 後按 **Ctrl+Z**
- JupyterLab：按 Esc 後按 **Z**

### JupyterLab 的黑色視窗不小心關掉了
重新雙擊 `2_啟動JupyterLab.bat`。檔案有自動存檔，不會不見。

### VS Code 介面變成英文
從隨身碟雙擊 `1_啟動VSCode.bat` 開（它會依目前的磁碟代號修正語言設定），不要直接開 Code.exe。

### `sk.explore()` 沒有出現輸入框（或只出現一部分）
VS Code 的互動元件偶爾會顯示不出來（VS Code 自己的問題，有網路也可能發生，斷網時更常見）。改用：
- **`sk.explore(text=True)`**：一問一答模式，VS Code 會在上方跳出輸入框，依序選分布、填參數、選問題，最後印出答案、課程寫法的程式碼並畫圖。不需要互動元件，斷網也能用（想再算一次就重新執行那一格）
- **JupyterLab**（`2_啟動JupyterLab.bat`）：互動介面是內建的，斷網也能用
- 或直接寫：`X = sk.Normal(80, 10)`，`X.P('X >= 90')`、`X.quantile(0.95)`、`sk.plot_dist(X, 'X >= 90')`；也可以用 snippets（`norm`、`binom`…）

## 四、匯出 HTML

### 怎麼匯出
擇一，三種都會檢查有沒有寫學號、執行順序、錯誤，並把 ipynb 和 html 備份到 `exam/_backup/`：
- VS Code：**Ctrl+Shift+P → 輸入「執行工作」→「匯出目前的 notebook 成 HTML」**（要先切到那份 notebook 的分頁）；選「（先從頭重新執行）」那個會先全部重跑
- 雙擊隨身碟根目錄的 `3_匯出HTML.bat`，從清單選
- 把 .ipynb 拖到 `3_匯出HTML.bat` 上

VS Code notebook 工具列「⋯ → 匯出 → HTML」也可以用，但不會做上面的檢查和備份。

### 匯出時出現 `ModuleNotFoundError: No module named 'nbconvert'`
用到了電腦上另一個 Python 的 nbconvert（考場電腦或你自己的電腦有裝 Python 時會發生）。v1.2.0 起已經修正；舊版請用新版精靈重新建立，或改用上面的「執行工作」或 `3_匯出HTML.bat` 匯出。

### 答案要怎麼寫
- 照考卷的格式：每一小題先 `print` 分隔線和「My answer for Subproblem 2A starts here:」（snippet `ans`、`ansblock`），答案也用 `print` 印出來
- 不需要四捨五入（除非題目要求）
- `sk` 印出的「程式碼」要貼進 cell 執行，匯出的 HTML 不需要 statkit 也看得懂

### 匯出的 HTML 沒有圖
匯出前那些 cell 沒有執行。先「重新啟動 → 全部執行」，再匯出。`3_匯出HTML.bat` 選 y 會自動先從頭執行。

### HTML 裡的公式顯示成 `$...$` 原始碼
斷網時本機預覽公式不會排版（HTML 用網路載入公式字型），上傳後助教看是正常的。

### `sk.explore()` 的畫面在 HTML 裡不見了
互動元件不會存進 HTML。把它下方產生的程式碼複製到新的 cell 執行，答案才會留在 HTML 裡。

### 檔名與學號姓名
考卷保留老師給的原檔名，匯出的 HTML 檔名也一樣（老師另外規定檔名的話，用檔案總管按 F2 改）。學號、姓名要自己依老師的格式寫在考卷裡；匯出時如果考卷裡找不到你的學號（`tools/student.json` 裡的）會提醒你。

## 五、統計常見錯誤

| 情況 | 正確寫法 | 常見錯誤 |
|---|---|---|
| 離散 Pr(X ≥ 10) | `1 - stats.poisson.cdf(k=9, mu=λ)` | 寫成 `cdf(k=10)`，**忘了減 1** |
| 離散 Pr(X < 10) | `stats.binom.cdf(k=9, n=n, p=p)` | 寫成 `cdf(k=10)` |
| 離散 Pr(a ≤ X ≤ b) | `cdf(b) - cdf(a - 1)` | 寫成 `cdf(b) - cdf(a)` |
| 指數分布 | `stats.expon.cdf(x, scale=1/λ)` | 寫成 `scale=λ` |
| 指數 / 卜瓦松的時間單位 | λ 每小時 6.6 次 → 25 分鐘寫 `25/60` | 單位沒換 |
| 常態分布 | `stats.norm.cdf(x, loc=μ, scale=σ)` | `scale` 放變異數 σ² |
| 均勻分布 Uni(a, b) | `stats.uniform.cdf(x, loc=a, scale=b - a)` | `scale=b` |
| 超幾何 Hyper(N, K, n) | `stats.hypergeom.pmf(k, M=N, n=K, N=n)` | 照課本的字母直接填 |
| 四分位數 | `statistics.quantiles(x, n=4)`（講義） | `pd.Series.quantile` 是另一種算法；題目沒指定就用講義的，並在答案寫出用了哪種 |
| 母體 vs 樣本 | 母體 `statistics.pstdev`、樣本 `statistics.stdev` | pandas `.std()` 預設是**樣本**（ddof=1） |
| 連續分布 Pr(X = x) | 一定是 0 | 用 `pdf(x)` 當機率（那是密度，不是機率） |
| 常態右尾反查「q 比例超過 x」 | `stats.norm.ppf(1 - q, loc, scale)` | 寫成 `ppf(q)`（那是左尾） |
| 樣本平均數的機率 | `scale=σ / math.sqrt(n)` | `scale=σ`（忘了除以 √n） |
| 「偏離 μ 超過 d」 | `2 * stats.norm.sf(μ + d, loc=μ, scale=se)` | 只算一邊 |
| 兩個獨立常態相加 | 標準差 `math.sqrt(σ1**2 + σ2**2)` | 標準差直接相加（那是同一個變數乘 2） |
| 直方圖疊 pdf | `plt.hist(..., density=True)` | 縱軸是次數卻直接疊 pdf（差了「筆數 × 組距」倍） |
| Cov = 0 | 只代表**不相關** | 說成獨立（獨立要每一格都等於邊際相乘） |
| 最小樣本數 | `math.ceil((z * σ / d) ** 2)`，z = `ppf((1 + prob) / 2)` | 四捨五入；z 用了單邊的 `ppf(prob)` |

不確定的時候，用 `sk.prob(分布, '條件')` 驗算，它會印出正確的寫法：
```python
sk.prob(sk.Poisson(6.6), 'X >= 10')
```

## 六、檔案與隨身碟

### 匯入老師給的考卷
- 雙擊隨身碟根目錄的 **`5_匯入考卷.bat`**，在跳出的視窗選老師給的 `.ipynb`（預設開在「下載」資料夾），或直接把檔案拖到 `5_匯入考卷.bat` 上
- 或在 VS Code 裡：**Ctrl+Shift+P → 輸入「執行工作」→「匯入考卷」**

會複製到 `exam/`（保留原檔名），在標題下面加一格 import 與初始設定，再用 VS Code 打開。先執行那一格再作答。考卷用到的資料檔（例如 `pd.read_excel('xxx.xlsx')`）如果跟考卷在同一個資料夾，會一起複製；找不到的話會提醒你下載後放到 `exam/`。`exam/` 裡已經有同名的考卷時不會蓋掉：直接 Enter 打開已經有的那份，輸入 `n` 另存一份 `原檔名_2.ipynb`。

選檔視窗沒出現：看一下工作列，它可能在其他視窗後面。

### 學號或姓名錯了
- 考卷裡的學號姓名是你自己寫的，直接改考卷就好
- 匯入考卷時的提醒、匯出時的檢查用的是 `tools/student.json`，用記事本打開修改

### 檔案改壞了，想回到之前的版本
- **VS Code 時間軸**：在左側檔案總管點一下那個檔案，檔案總管最下方展開「**時間軸**」，會列出之前每次存檔的版本；點一下可以比較差異，右鍵可以還原
- **匯出時的備份**：`exam/_backup/` 裡有每次匯出時的 ipynb 和 html（檔名後面是時間）
- **JupyterLab**：File → Revert Notebook to Checkpoint（回到上一個檢查點）

### 拿到資料檔，先看裡面有什麼
```python
df = sk.peek('檔名.xlsx')     # 資料跟考卷在同一個資料夾；自己練習放 data/ 的話寫 '../data/檔名.xlsx'
```
CSV 打開是亂碼時，`sk.peek` 也會自動試 `cp950`（Big5）編碼。
讀進來之後要做什麼（檢查型態、缺值、整理欄位、篩選、分組統計），照 [讀入資料與整理](notes/00_讀入資料與整理.ipynb) 的步驟做；snippet `readcheck` 可以一次插入讀檔後的標準檢查。

### 拔隨身碟之前
1. 先存檔，關掉 VS Code；用 JupyterLab 的話也要關掉那個黑色視窗
2. 再到右下角系統匣按「**安全地移除硬體並退出媒體**」

直接拔可能讓還沒寫完的檔案壞掉。
